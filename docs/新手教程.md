# 拾忆 新手教程

> 从零开始，20 分钟把拾忆跑起来。看不懂名词没关系，照着点就行。
> 适用版本：**2.6.11+**（Android 8.0+ / Windows 10+）

---

## 第 0 步：先准备两样东西

1. **一台设备**：安卓手机（Android 8.0 以上），或 Windows 电脑。
2. **一个模型 API Key**：拾忆本身不含模型，它调用你提供的模型接口。常见来源见下表。

| 服务商 | Base URL（填在设置里） | 说明 |
| --- | --- | --- |
| DeepSeek 官方 | `https://api.deepseek.com` | 便宜、中文好，新手推荐 |
| 小米 MiMo | `https://token-plan-cn.xiaomimimo.com/v1` | 国内直连快 |
| OpenAI | `https://api.openai.com/v1` | 需要海外网络 |
| Anthropic | `https://api.anthropic.com` | Claude 系列 |
| OpenRouter | `https://openrouter.ai/api/v1` | 一个 Key 用很多模型 |
| 自建 / 中转 | 服务商给你的地址 | 一般以 `/v1` 结尾 |

> 记不住就先只拿一个：**DeepSeek 官方**最容易上手。

---

## 第 1 步：安装

### 安卓手机

1. 打开 [Releases 页面](https://github.com/JIUSIS/shiyi-agent/releases)，下载最新那个 **`shiyi-agent-v2.6.11.apk`**（约 19 MB）。
2. 点开安装包 → 系统提示"未知来源"就允许一次 → 安装。
3. 首次启动会**自动部署内置终端环境**（约 4 MB 资产 + 初始化），等它跑完，别急着退出。

### Windows 电脑

从 Release 里下载 Windows 包，**解压整个目录**后运行 `shiyi_agent.exe`。
（不要只把 exe 单独拖出来，它需要同目录的依赖文件。）

> **升级时永远直接覆盖安装，不要卸载。** 卸载会清掉 API Key、会话和记忆。
> 命令行升级用：`adb install -r shiyi-agent-v2.6.11.apk`

---

## 第 2 步：配置模型（最关键的一步）

1. 打开 App → 底部 **功能** 栏 → **设置**。
2. 进 **模型**（有的版本叫「模型与 API」）→ 点 **新增配置**。
3. 填三样：
   - **Base URL**：上表对应地址（例如 `https://api.deepseek.com`）
   - **API Key**：你申请到的那串密钥
   - **协议**：一般选 `OpenAI 兼容`；只有明确是 Claude 官方接口才选 `Anthropic`
4. 点 **获取模型**（或「拉取模型列表」）→ 从列表里选一个。
   - 拿不到列表也没关系，手动输入模型 ID 也行，例如 `deepseek-chat`。
5. 点 **测试连接** → 显示成功就完成了。
6. 回到设置顶部，把这个配置设为**默认配置**。

> 卡住了？90% 的情况是：Base URL 少了 `/v1`、Key 前后带了空格、或者手机网络连不上该服务。见文末「常见问题」。

---

## 第 3 步：说第一句话

1. 底部 **会话** 栏 → **新建项目** → 选一个文件夹（建议专门建一个，比如 `Documents/拾忆项目`）。
2. 在项目卡片上**左滑** → **新建会话**。
3. 在底部输入框打一句话，比如：

   > 你好，介绍一下你自己，然后告诉我这个工作目录里有什么文件。

4. 回车发送。你会看到**思考过程**先出来（可折叠），然后才是正文。

**记住三个概念**（后面一直用）：

- **项目** = 一个文件夹 + 一组会话。项目里建的会话默认都在这个文件夹里干活。
- **会话** = 一段独立对话，有自己的上下文和记忆。
- **工作目录** = AI 读写文件、跑命令的"当前所在文件夹"。项目里能统一设置，单个会话也能覆盖。

---

## 第 4 步：让它真的动手干活

拾忆和普通聊天 AI 的区别：**它真的会读写文件、跑命令**。试这几句：

| 你说 | 它会做 |
| --- | --- |
| `看看这个目录里有什么` | 调 `file_read` / `run_terminal` 列出文件 |
| `把 notes.md 里的错别字改掉` | 读文件 → 改 → 写回 |
| `写一个 pelican_bike.svg 画一只骑车的鹈鹕` | 直接生成文件保存到工作目录 |
| `跑一下 python3 算 1 到 1000 的质数和` | 调终端执行并返回结果 |
| `搜一下 xxx 最新进展` | 联网搜索 + 抓取网页 + 交叉验证 |

**怎么看它到底改了什么**：回复气泡下方有**工具胶囊**，点开就是

- **完整入参**（实际执行的命令 / 文件路径）
- **完整输出**（命令结果，或**代码改动差分**：绿色的新增行、红色的删除行）

会话页顶栏的终端图标可以打开**调用日志**，看本轮所有工具调用的完整入参与输出。

---

## 第 5 步：几个立刻能提升体验的功能

- **技能**：输入框打 `/`，会弹出技能列表（资料整理、代码分析、写报告等）。也可以自己导入技能包。
- **记忆**：直接说「记住：我习惯用中文注释」——它会存进长期记忆，以后自动带上。功能页 → 记忆 可检索、管理。
- **@ 引用**：输入 `@` 会弹出工作区文件与会话候选，选中即插入，让 AI 精确读某个文件。
- **附件**：输入框旁的回形针可以发图片（需要视觉模型）和文件。
- **思考档位**：会话页顶部的思考按钮可调 off / low / medium / high / max；越高的档位推理越深、越慢。档位按模型自动识别。
- **发消息前先看缓存命中率**：输入框上方的统计栏会显示本轮缓存命中情况，命中率高=更快更省钱。
- **上下文管理**：长会话会自动压缩；也可以随时点输入区的压缩按钮手动压缩。

## 第 6 步：群聊（让多个 AI 组成一个团队）

这是拾忆最有意思的部分：不是一个 AI 陪你聊，而是**多个不同角色的 AI 按公司结构协作**——领导派活、下属并行干活、逐级汇报。

### 建一个群

1. **会话** 栏顶部有「群聊」入口（功能页也有群聊列表）。
2. 新建群聊 → 可以**粘贴一段 mermaid 或字符画的思维导图**，它会自动识别出有几个角色、谁向谁汇报。
3. 每个成员可以单独设置：名字、职位、人设、以及**用哪个模型**（比如领导用强模型，码手用便宜的）。
4. 保存后开始对话。

### 它是怎么动的（很重要）

- **只启动被叫到的人**：你不点名时，只有对接你的那位（负责人）会动；
- **负责人用 `@名字` 派活**：叫几个人就**同时几条线程**并行干；
- **一批全部汇报完，才轮到下一批**：领导不会拿着半成品开工；
- **`@` 不等于立刻启动**：文档里提到的名字、条件句里的名字（"通过后再让 @乙 做"）不会误启动；
- 每个成员的**思考过程、工具调用、代码改动**都显示在它自己的气泡里。

### 用起来像这样

> 你：@经理 帮我把这个 SVG 优化一下，再写个 README 说明
> 经理：收到，拆两棒 → @码手A 改 SVG，@码手B 写 README（两人同时开始）
> 码手A / 码手B：（并行干活，各自汇报路径和结果）
> 经理：（两人都汇报完）验收 → 汇总给你

群里点工具胶囊能看**完整命令与输出**；顶栏终端图标是**调用日志**。

## 第 7 步：底部「终端」栏

底部第四栏是内置终端，**不用另装 Termux**：

- 它是设备内的 Alpine Linux 环境（`apk` 装包、bash、python3 都能用）；
- **点画面输入**命令，回车执行；执行中输入仍可用；
- 双指**捏合缩放字号**；输入时自动补全命令前缀；
- 输出按颜色区分：正常灰绿、警告黄、错误红。

> 没有 root 的手机可能受系统 SELinux 限制导致终端不可用，这是平台限制，不是 App 的 bug。

## 第 8 步：接入 DeepSeek Harness（DSH，可选）

想用 DSH 引擎（而不是拾忆本地引擎）时：

1. 功能页 → **Agent 引擎** → 切到 **DeepSeek Harness**。
2. 选连接方式：
   - **本机**：直接在手机上安装并启动（App 会帮你装好 Node 环境）
   - **局域网**：电脑上跑着 DSH，手机填**电脑的局域网 IP + 端口**（如 `192.168.1.8:3080`）。电脑端 DSH 需要监听 `0.0.0.0`，手机不要填 `127.0.0.1`
   - **公网**：填 DSH 的完整 URL；如有 Token 一并填
3. 在「模型数据」页把拾忆里的 API 配置接给 DSH 用：
   - 本机 / 局域网走**手机临时中转**（真实 Key 不离开手机）
   - 公网走**直接注入**（Key 会写入目标 DSH，请只对你自己的服务器这么做）
4. 之后 DSH 会话就支持：附件直接发送、`/` 斜杠命令、`@` 引用工作区文件、后台任务、消息反馈、定时任务、插件管理、会话分叉等。

---

## 第 9 步：关于「输出上限」（重要，别自己掐断模型）

设置 → 上下文里有四项长度限制，**默认全是 `0` = 不限制**：

| 设置项 | 默认 | 含义 |
| --- | --- | --- |
| 输出上限 | `0` | 不发送 `max_tokens`，用模型自己的最大输出 |
| 长推理等待上限 | `0` | 不套超时，等模型慢慢推理 |
| 自动续写轮数 | `0` | 一直续写，直到没有新内容 |
| 工具轮数上限 | `0` | 工具循环不限轮数 |

**除非你想省钱或限速，否则不要动它们。** 如果你之前被"回答到一半就断"，先检查这里是不是被设成了 8192 之类的数字。

> 老版本升级上来的用户，App 会自动把旧默认值（8192 / 600 / 16）迁成"不限制"，你自己改过的值不会被覆盖。

## 常见问题

**Q：我该装哪个包？**
A：安卓手机装 `shiyi-agent-vX.Y.Z.apk`（只支持 arm64，近几年的手机都是）。Windows 装 Release 里的 Windows 包。

**Q：升级会不会丢数据？**
A：不会，前提是**覆盖安装**（直接装新 APK，不要先卸载）。

**Q：回答到一半就断了 / 输出被截断？**
A：设置 → 上下文，确认四个上限是 `0`。若仍是断，看会话下方提示——可能是上游服务商自己截断，App 会告诉你原因。

**Q：老是提示网络连接失败？**
A：App 每轮都会自动重试 2 次；若持续失败，检查：手机能不能访问该 API（浏览器试一下）、Base URL 是否写错、是否需要在设置 → 通用 → SOCKS5 里配代理。

**Q：为什么发消息后要等一两秒才出字？**
A：开启「活人感」（LAAP）时会多一次本地认知状态请求，最多 0.9 秒，超时就跳过不影响回复。不需要可在 Agent 引擎页关掉。

**Q：终端里 `apk add` 报 Permission denied？**
A：无 root 设备受 SELinux 限制，属平台限制。有 root 的机型 App 会自动补策略。

**Q：AI 说找不到文件？**
A：看**当前会话的工作目录**（会话标题下方/设置里）。让它 `pwd` 看一眼最直观；也可以直接说「列一下当前目录」。

**Q：怎么让它读另一个会话的内容？**
A：在会话卡片左滑 → 复制 ID → 把 ID 发到另一个会话，让它用跨会话检索去读。

**Q：群聊里我叫了一个人，别人也动了？**
A：已修：只有真正被指派的人会启动，文档里提到的名字不会误启动。若还遇到，把那条消息发给我们。

**Q：Windows 版怎么关窗口/最小化？**
A：窗口左上角有红黄绿三键（macOS 风格），双击标题栏最大化，边缘可拖拽缩放。

## 隐私与数据

- 会话、设置、长期记忆、项目文件**默认只存在本机**，拾忆不上传任何服务器；
- 发给模型的内容取决于你配置的 API 服务与对话内容；
- 使用第三方模型服务时，请阅读对应服务商的隐私政策；
- 公网 DSH 的"直接注入"会把真实 API Key 写入你自己的目标服务器，这是你自己知情选择的行为。

---

## 还是不会？

按顺序自查：

1. 模型配置页点 **测试连接**，通过了吗？
2. 手机/电脑能正常打开那个 API 地址吗？
3. 设置 → 上下文，四个上限是不是 `0`？
4. 功能页 → 日志，看最后一次请求报了什么错。

把这三处的截图发到 [GitHub Issues](https://github.com/JIUSIS/shiyi-agent/issues) 或社区，会快很多。
